# v0.5：官网资料总结、账号与云端聊天

联网查询使用 Tavily advanced 搜索，最多6个官网结果；并行提取前3个结果正文，从最相关结果继续爬取官网内部页面（深度2、每层3个链接、最多3页）。所有输入与返回 URL 都校验院校域名；外部链接不采集。相关接口见 [Search](https://docs.tavily.com/documentation/api-reference/endpoint/search)、[Extract](https://docs.tavily.com/documentation/api-reference/endpoint/extract)、[Crawl](https://docs.tavily.com/documentation/api-reference/endpoint/crawl)。爬取并非整站离线镜像；网站不可达、验证码或反爬仍会影响正文可用性。提取失败保留搜索摘要。

相同院校、问题和类别的结果缓存10分钟，最多64条；不落盘或记录提问日志。一次查询最多32秒搜索、24秒总结及10秒本地匹配，客户端等待75秒。高级检索和正文提取会使用 Tavily 额度。

DeepSeek 输出最多5段结构化总结（heading、text、support），优先结论，再提供与问题相关的步骤/材料/注意事项。每段引用键必须存在，支撑引文必须为对应正文的连续子串。校验允许换行、Markdown加粗及部分全/半角标点差异，并将引文替换为实际原文片段；不能改变数字、添加文字或用省略号拼接。逐段校验，不合格段落剔除，有效段落保留。模型可以归纳，但不能增加规定，必须保留年份和适用对象。引文校验不能机械证明归纳句的全部语义，因此页面仍标明 AI 整理、未经人工审核。来源与旧版长摘录折叠查看，不把原始整页正文堆进聊天。

## 账号与云端

账号服务需要 `CAMPUS_DATA_DIR`，Compose 使用 `campus-data` 命名卷挂载 `/app/data`。数据库 `accounts.sqlite3` 使用 SQLite WAL。用户名3–32位字母/数字/下划线，统一小写；密码8–128位，保存为独立随机盐的 scrypt 摘要。30天随机登录令牌只保存 SHA256 摘要，最多10个设备登录；退出撤销当前令牌，删除账号撤销全部令牌。注册/登录/账号删除限制单IP10次/分钟、全局60次/分钟，适用于当前单 worker。

API：`POST /auth/register`、`POST /auth/login`、`GET /auth/me`、`POST /auth/logout`、`DELETE /auth/account`（密码确认），均位于 `/api/v1` 下。账号接口禁止 HTTP 缓存。手机令牌使用 Android KeyStore 支持的安全存储，不保存密码或将令牌写进聊天 JSON；[插件说明](https://pub.dev/packages/flutter_secure_storage/versions/9.2.4)。当前不提供邮件验证、密码找回或学校身份认证。

`GET /sessions` 拉取当前账号的对话及删除标记；`PUT /sessions/{id}` 携带已知 revision 与 data；`DELETE /sessions/{id}?revision=...` 删除并保留版本标记。服务端按用户隔离，拒绝过期版本（409）。每个账号最多50个有效对话，单个最多100条消息、200KB。手机遇到多设备同时修改时另存本机版本，保留云端版本；遇到断网保留待同步状态。需要同步的本机修改不因最近20个对话的普通缓存裁剪被删除。大对话超过配额时会提示新建对话。

游客仍可直接使用。登录后的新对话自动同步；已有游客对话需在账号页明确点击“导入本机历史”。资料夹、图片、材料勾选和提醒不上传。退出时删除该账号本机聊天缓存，但服务器记录保留；删除账号需密码确认，永久删除账号和云端记录。单条聊天删除会同步到云端；“清除本机数据”只清本机，云端历史可再次同步。

## 界面与验证

保留绿色校园风格，优化欢迎区、输入框、账号面板和来源入口。增加页面切换渐变、消息淡入位移、检索脉冲和系统底部面板转场；系统“减少动画”开启时停用自定义运动效果。操作期间显示状态并防止重复提交。

后端回归覆盖官网正文与内部链接、缓存、归纳引用校验、搜索失败降级、账号密码与令牌存储、账号隔离、过期版本、删除标记、数据库重启和配额。Flutter 回归覆盖安全存储接口、重启登录、退出、自动同步、并发修改保留与来源折叠，并继续执行历史/OCR测试与手机尺寸截图。APK 由 GitHub Actions 构建。

## 数据维护

服务器备份使用 SQLite 在线备份 API，而非运行中直接复制单个主文件；备份必须包含数据库一致性快照。修改镜像、重建容器不会删除命名卷。不要执行 `docker compose down -v`。该 SQLite 数据库包含云端聊天文字，备份文件应限制为0600，不放入 Git 仓库；没有用户内容写入访问日志。
