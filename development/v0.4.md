# v0.4：本机资料、院校与联网证据

## Android 使用

- 消息、当前院校、搜索/离线开关、材料勾选在应用私有目录保存。新对话保留历史，可从“本地资料与提醒”恢复。最多保留20个对话，每个100条消息，以及100份保存资料。
- 办事卡片可保存到资料夹、设置提醒。提醒使用手机系统本地通知，需授权通知权限，非云端推送；时间按手机本地时间选择，系统省电策略可能延迟通知。重启由 Android 接收器恢复已有计划。
- 打开“离线资料”后发送事项关键词，仅查本机所选院校的已保存资料与历史答复，不调用后端。历史内容可能过期，不代表现行规定。
- 扫描按钮支持拍照或相册，用打包的 ML Kit 中文模型在设备上识别；结果可编辑，确认后仅填入问题，不自动发送。照片不上传到 API，也不进入对话存储。
- 切换院校会开启新对话，本地记录与知识库均按院校隔离。内置4所院校，也可输入院校全称与官网域名添加自定义院校；自定义官网归属由用户确认。
- 资料页可删除单个资料、对话和提醒，或清除全部本机数据。Android 云备份关闭，卸载仍会清除数据。当前 APK 仍使用开发签名，不保证跨版本覆盖安装。

## 搜索与分析

联网开关默认关闭。打开后，API 通过 Tavily `POST https://api.tavily.com/search`，设置 `include_domains` 为院校官网、`include_domains_mode=restrict`、最多5条结果、basic 搜索、禁止搜索商生成回答。服务端再次校验 URL 主机，阻止相似域名与其他院校混入；不会抓取用户提供的任意 URL。

DeepSeek 从所选院校最多8条有效审核记录与搜索摘要中筛选相关证据。输出必须包含真实引用键和连续原文摘录，逐条校验后展示；未知引用或不在证据中的断言会被丢弃。网络资料不直接生成正式办理卡片。网络摘要、检索时间、未审核标记与原文链接同时展示。日期、对象和本地资料差异需要用户核对学校原文；这是证据筛选与对照，不是开放域自由生成。

请求增加 `school_id`、自定义时的 `school_name/school_domain`、`search_enabled`；旧客户端缺省为创业学院且关闭搜索。知识记录增加 `school_id`，旧记录归属创业学院，新院校必须在入库时指定。`GET /api/v1/schools` 返回服务端内置院校。

搜索失败或未配置不会阻断本地查询。AI/搜索共用现有每IP6次/分钟、全局30次/分钟、最多2个并发的单进程限额。搜索总时限12秒，模型筛选10秒，证据分析14秒；客户端等待45秒。原始照片、问题及密钥不写服务日志。

## 配置 Tavily

在服务器 `/opt/campus-assistant/infra/.env` 增加 `TAVILY_API_KEY`，保持文件权限0600。不要提交到仓库或写入 APK。然后执行：

```sh
cd /opt/campus-assistant
docker compose --env-file infra/.env -f infra/compose.yaml -f infra/compose.tls.yaml up -d --wait
```

健康检查 `https://v4.yukifn.xyz:7010/health` 应显示 `search_provider=tavily`、`search_status=configured`。这仅验证配置；实际搜索需要发送 `search_enabled=true` 的提问，再确认 `search_status=used` 且 URL 属于选定院校官网。未配置时为 `not_configured`，真实付费额度与网络可用性以搜索服务返回为准。

接口适配依据：[Tavily Search 官方协议](https://docs.tavily.com/documentation/api-reference/endpoint/search)。
