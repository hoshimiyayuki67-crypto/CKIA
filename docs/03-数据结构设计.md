# 03 数据结构设计

> 对应代码：[app/schemas/](../app/schemas)、[app/data/](../app/data)。

## 一、知识库条目结构

单条知识库片段，作为检索与出处标注的最小单位。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| doc_id | string | 文档唯一标识 |
| title | string | 文档标题 |
| issuer | string | 发布部门 |
| publish_date | date | 发布日期 |
| category | string | 事务类别（资助/教务/财务/学籍/就业/生活） |
| layer | string | official / experience |
| chunk_id | string | 切分片段标识 |
| chunk_text | text | 片段正文 |
| vector | float[] | 向量表示 |
| valid_until | date | 有效期（可为空） |

对应 `app/schemas/knowledge.py` 的 `KnowledgeChunk`；召回时附加 `score` 字段形成 `RetrievedChunk`。

## 二、办事卡片结构

系统返回的结构化结果，是产品的核心价值载体。

| 字段 | 类型 | 必填 | 为空时处理 |
| --- | --- | --- | --- |
| matter_name | string | 是 | 不可为空 |
| target_users | string[] | 是 | 必填 |
| materials | object[]（item / required / note） | 是 | 必填 |
| location | string | 是 | 显示「未查到明确信息」 |
| office_hours | string | 是 | 显示「未查到明确信息」 |
| deadline | date | 否 | 显示「未查到明确期限」 |
| channel | string | 是 | 显示「未查到」 |
| contact | string | 是 | 必填 |
| sources | object[]（title / issuer / date） | 是 | 必填 |
| notes | string[] | 否 | 自动隐藏 |
| confidence | float | 是 | < 0.6 时附加「信息可能不完整」 |

对应 `app/schemas/card.py` 的 `ActionCard` / `Material` / `SourceRef`。

**容错约束**：任何字段未从知识库抽取到时，一律以「未查到明确信息」兜底，**绝不允许模型自行填充**。

## 三、会话日志结构（匿名化）

| 字段 | 说明 |
| --- | --- |
| session_hash | 会话标识的不可逆哈希，不含任何身份信息 |
| question_text | 脱敏后的提问文本 |
| intent | 识别出的事务类别 |
| hit | 是否命中知识库 |
| answer_given | 是否给出有效回答 |
| feedback | 用户反馈（有用/没用） |

对应 `app/core/analytics.py` 的 `QueryLog`。

## 四、拒答结构

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| intent | string | 识别出的事务类别 |
| message | string | 拒答说明 |
| contact | string | 咨询渠道（部门/电话/地点） |

对应 `app/schemas/card.py` 的 `Refusal`。

## 五、学期时间轴配置

以 YAML 维护，调度器每日扫描。

```yaml
- id: score_review
  name: 成绩复核
  window: "期末后 5 日内"
  remind_before: 3          # 提前 3 天提醒
  category: 教务
  card_template: score_review_card
```

| 字段 | 说明 |
| --- | --- |
| id | 唯一标识 |
| name | 事项名称 |
| window | 触发窗口（自然语言描述，供人工维护与展示） |
| remind_before | 提前提醒天数 |
| category | 事务类别 |
| card_template | 推送所用卡片模板标识 |

完整配置见 [config/timeline.yaml](../config/timeline.yaml)。

## 六、存储规划

| 数据 | 存储载体 | 生命周期 |
| --- | --- | --- |
| 知识片段与向量 | Chroma（开发）/ Milvus（生产） | 长期，随文档版本更新 |
| 知识库原文 | 文件系统 / 对象存储 | 长期 |
| 会话上下文 | 内存（开发）/ Redis（生产） | 会话期内 |
| 匿名提问日志 | 关系库 / 分析库 | 按学校数据保留策略 |
| 学期时间轴 | YAML 配置 | 每学期更新 |
